# fintech-terminal-ui

Интерфейс спотового торгового терминала на React 19, TypeScript, Tailwind CSS и TradingView Lightweight Charts.

Дизайн интерфейса спроектирован с опорой на спецификации дизайн-системы **Coinbase** (из коллекции [awesome-design-md](https://github.com/VoltAgent/awesome-design-md)): глубокий контрастный фон, строгая типографика, плотная компоновка аналитических данных и акцентные фирменные цвета.

## Возможности
- Интерактивный свечной график на canvas с переключением таймфреймов (1m, 5m, 15m, 1h, 1d).
- Стакан заявок (Order Book) с динамической глубиной и расчетом спреда.
- Лента сделок с автоматическим обновлением тиков.
- Форма размещения лимитных и рыночных ордеров с быстрым выбором доли депозита (25%, 50%, 75%, 100%).

## Запуск

```bash
npm install
npm run dev
```

Локальный сервер запустится по адресу `http://127.0.0.1:5174/`.
