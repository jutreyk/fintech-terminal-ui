# fintech-terminal-ui

Интерфейс торгового терминала на React 19, TypeScript, Tailwind CSS и Lightweight Charts. Визуально вдохновлен спотовым терминалом Coinbase.

## Возможности

- Свечной график с таймфреймами (1m, 5m, 15m, 1h, 1d) и скользящей средней SMA.
- Стакан заявок (Order Book) с расчетом спреда.
- Лента сделок с живым потоком тиков.
- Форма для лимитных и рыночных ордеров с быстрым выбором доли баланса (25%, 50%, 75%, 100%).

## Запуск

```bash
npm install
npm run dev
```

Сервер запустится на `http://127.0.0.1:5174/`.
